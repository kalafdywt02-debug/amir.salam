# امیر.سلام — نسخه اصلاح‌شده آفلاین

این نسخه برای تست روی Android 14 آماده شده است.

## اصلاحات این نسخه

- مشکل وابستگی اشتباه `kotlinx.serialization` حذف شد.
- AccessibilityService قوانین ذخیره‌شده DataStore را واقعاً می‌خواند.
- سرویس فقط قوانین فعال را استفاده می‌کند.
- متن‌های حساس مانند رمز، PIN و OTP فیلتر می‌شوند.
- دکمه روشن فقط وقتی Accessibility واقعاً فعال باشد سرویس را فعال نشان می‌دهد.
- برنامه همچنان بدون Root و بدون اینترنت برای منطق اصلی کار می‌کند.
- هیچ تغییر ریشه‌ای در Android یا APK برنامه‌های دیگر انجام نمی‌شود.

## محدودیت مهم

جایگزینی ۱۰۰٪ همه متن‌های همه برنامه‌ها با یک برنامه معمولی Android ممکن نیست.
این نسخه فقط در جاهایی که Accessibility مقصد اجازه و داده لازم را در اختیار
سرویس قرار دهد می‌تواند متن قابل ویرایش را تغییر دهد. متن‌های غیرقابل ویرایش،
Canvas، بعضی WebViewها و رابط‌های محافظت‌شده ممکن است قابل تغییر نباشند.

## ساخت APK فقط با گوشی

### گزینه پیشنهادی فعلی: Android IDE - PHONE AS

این پروژه یک پروژه Gradle/Android Studio است. یک IDE موبایلی که در Google Play
در دسترس است و در صفحه خود پشتیبانی از پروژه‌های Android Gradle و ساخت APK روی
خود دستگاه را اعلام کرده، می‌تواند برای این کار استفاده شود.

مراحل:

1. از Google Play برنامه `Android IDE - PHONE AS` را نصب کن.
2. ZIP پروژه را استخراج کن.
3. داخل برنامه، گزینه Open/Import Project را انتخاب کن.
4. پوشه اصلی `AmirSalam-Final-Offline` را انتخاب کن؛ همان پوشه‌ای که
   `settings.gradle.kts` داخل آن است، نه پوشه `app`.
5. صبر کن تا Gradle Sync تمام شود.
6. اگر برنامه SDK یا JDK خواست، گزینه نصب/تنظیم پیشنهادی خودش را انتخاب کن.
7. از منوی Build، گزینه Build APK/Debug APK یا Run را انتخاب کن.
8. بعد از موفقیت، APK را نصب کن.
9. در Android 14 اگر اجازه نصب از آن منبع خواسته شد، برای همان برنامه مدیریت
   فایل/IDE اجازه Install unknown apps را فعال کن.

## تست

بعد از نصب:

1. «امیر.سلام» را باز کن.
2. در ابتدا ۸ قانون پیش‌فرض را ببین.
3. به «اسم‌ها» برو و یک قانون جدید بساز.
4. برای قابلیت بین‌برنامه‌ای، Accessibility را در تنظیمات Android فعال کن.
5. برگرد به برنامه و وضعیت دسترسی‌پذیری را بررسی کن.
6. متن‌های قابل ویرایش را در یک برنامه آزمایشی امتحان کن.

## ساخت از ترمینال AndroidIDE

اگر IDE ترمینال و Gradle Wrapper پروژه را فراهم کرده باشد، دستور معمول:

`./gradlew assembleDebug`

است.

خروجی معمول:

`app/build/outputs/apk/debug/app-debug.apk`

اگر IDE خودش Gradle را مدیریت می‌کند، همان گزینه Build APK را استفاده کن.

## ادعای سازگاری

این برنامه با هدف سازگاری گسترده با دستگاه‌های Android 14 طراحی شده است.
قابلیت‌های پایه مستقل از Shizuku و Accessibility هستند، اما قابلیت‌های پیشرفته
ممکن است بسته به سازنده دستگاه، نسخه رابط کاربری، مجوزهای کاربر و محدودیت‌های
Android متفاوت باشند.

این نسخه ادعای «تغییر همه متن‌های Android» یا «سازگاری ۱۰۰٪» ندارد.

## ساخت APK بدون Android Studio

برای ساخت APK می‌توانید `BUILD_APK.bat` را اجرا کنید. این اسکریپت JDK 17 را پیدا می‌کند و در صورت نبودن Gradle 8.9، آن را از منبع رسمی Gradle دریافت می‌کند.

برای ساخت و نصب مستقیم روی گوشی، USB Debugging را فعال کنید، گوشی را با USB وصل کنید و `BUILD_AND_INSTALL.bat` را اجرا کنید. در اولین اتصال، پیام تأیید RSA روی گوشی را قبول کنید.

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

این روش برای Build به Android Studio نیاز ندارد، اما برای Android SDK باید SDK لازم روی رایانه نصب باشد.
